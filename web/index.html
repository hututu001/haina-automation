空闲中
点上方按钮开始；输出会实时显示在这里。
每个按钮做什么？
签到：查今日 token 消耗（≥100 万才签）→ 钱包签到 → 自动领取所有可领福利（含签到抽奖机会）。已领过的不会重复领。开了「签到后自动抽奖」会接着把奖抽了（次数遵循抽光设置）。
抽奖：先显示余额 / 可抽次数再抽。默认只抽 1 次；设置里开了「抽光模式」就一次抽完全部次数。次数不足时只报状态不抽。
农场：一键收菜（只收成熟的）→ 空闲地补种（种子库存优先，不够自动买，买前校验余额；默认种时薪最高的）→ 待兑换额度兑成主站余额（受本周 40% 消耗上限约束）。
农场+偷菜：上面全部 + 偷菜（3 体力/次，自动扫描全服可偷目标；竞争激烈，常常无可偷）。
偷菜：只偷菜，不收菜不补种（3 体力/次，自动扫描全服可偷目标）。设置里填了「偷菜时间」后到点自动偷；农场任务与偷菜完全分开，互不影响。
兑换：把待兑换额度单独兑成主站余额（受本周 40% 消耗上限约束），不收菜不补种。设置里填了「兑换时间」后农场任务不再顺手兑换，到点自动单独兑。
状态总览：只读。抽奖面板 + 农场一次看全，不做任何写操作，随时可点，也用于刷新过期会话。
